Taxi Booking System

Python Tkinter GUI MySQL / phpMyAdmin

A desktop management solution engineered in Python using Tkinter and connected to a MySQL database via phpMyAdmin[cite: 1]. The system automates ride scheduling, driver assignments, and trip tracking through role-based access control[cite: 1].

Role-Based Access & Architecture

Customer Interface

Allows users to input pickup/drop-off locations, schedule dates/times, view trip cost estimates, and manage booking requests (create, update, cancel)[cite: 1].

Driver Interface

Enables drivers to mark availability status, view assigned trip queues, update ride statuses (In-Progress, Completed), and review earnings history.

Admin Dashboard

Provides complete CRUD administrative oversight across all users, manually overrides driver assignments, and accesses system logs[cite: 1].

Core Logic Specifications

Trip Allocation & Status Lifecycle

[Customer Request] → Status: "PENDING"
  → [Driver Availability Check: `driver_status == 'AVAILABLE'`]
  → [System/Admin Assignment] → Status: "ASSIGNED"
  → [Trip Start] → Status: "IN_PROGRESS"
  → [Trip Completion] → Status: "COMPLETED" & Driver Status: "AVAILABLE"

Database Relations & Data Integrity

  • Relational Schema: Built on relational tables (`Users`, `Drivers`, `Bookings`, `Payments`) managed in phpMyAdmin[cite: 1].
  • Foreign Key Constraints: Links each booking record directly to a valid `Customer_ID` and assigned `Driver_ID`.
  • Conflict Avoidance Logic: Queries driver assignment state before committing booking updates to prevent double-booking active drivers.
