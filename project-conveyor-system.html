Conveyor & Pick-to-Light System

A warehouse automation simulation platform engineered to replicate physical tote routing, PLC sensor integration, and real-time operator guidance.

Project Overview

This system simulates high-speed order fulfillment workflows found in modern distribution centers. It bridges software control systems with physical conveyor hardware logic, managing item movement, diverting totes to specific picking zones, and driving pick-to-light displays for human operators.

Core Functionality & Architecture

  • • PLC & Sensor Abstraction: Simulates photoelectric sensors, barcode scanners, and pneumatic diverter switches asynchronously to maintain realistic timing constraints.
  • • Real-Time Telemetry: Leverages SignalR WebSockets to stream live tote location tracking, line speed measurements, and error state indicators to administrative web dashboards.
  • • Pick-to-Light Guidance: Coordinates visual LED cues and quantity displays at operator workstations, drastically reducing pick errors during order fulfillment.
  • • Containerized Deployment: Built and containerized using Docker to enable cross-platform execution and standardized local integration testing.

Key Engineering Challenges

Managing accurate event synchronization across rapid conveyor state transitions was a primary challenge. By implementing thread-safe queue handling and event-driven state machines, the application prevents race conditions when tracking multiple totes simultaneously.
