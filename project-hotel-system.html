Hotel Management System

A multi-tier desktop application built with Java Swing and JDBC to handle hospitality workflows. The system streamlines reception operations, room bookings, check-in/checkout processing, room service tracking, and automated billing.

System Modules & Operations

1. Room Availability & Reservation Engine

Receptionists can filter available rooms by category (Single, Double, Suite) and date ranges. The system validates availability before writing dynamic reservation records to the MySQL database.

2. Check-In / Check-Out Processing

Automates state transitions for rooms (Vacant, Occupied, Cleaning). Processing a check-out locks room service additions and calculates stay durations.

3. Room Service & Add-On Billing

Links food, beverage, and cleaning orders directly to active room sessions, dynamically accumulating charges into the customer's master tab.

Core Logic Specifications

Automated Billing Algorithm

The checkout module calculates total costs using standard night-rate formulas combined with active service charges:

Total Bill = (Stay Duration in Nights × Base Room Rate) + ∑(Room Service Orders) + Taxes/Fees

Database Architecture & Persistence

  • JDBC Connection Management: Employs structured PreparedStatements to execute secure parameterised queries and protect against SQL injection.
  • Transaction Atomicity: Uses MySQL transactions during checkout to update room availability state and mark invoice payments simultaneously.
